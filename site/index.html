artscript

A small language for procedural art. One text file builds painted PNG, SVG and GIF.

artscript check --json
artscript build

Your model writes it, checks it and fixes it.

Painted, not plotted

One hex, a whole ramp.

A ramp turns one hex into a run of stops, with shadows shifting toward cool blue-violet and lights toward warm yellow. Each of the five wing palettes lifted from lib/palette/moths.art is one hex and seven stops, and every chip here is one stop.

palette moths
  ramp luna #b9cfae 7
  ramp dusk #5d6686 7
  ramp ember #c2703f 7
  ramp bone #e6dfd0 7
  ramp rosy #e39ab0 7

each r, wing in [luna dusk ember bone rosy]
  each i in 0..7
    rect 70x54 r:5 at:124+i*92,82+r*84 fill:p.{wing}.{i} brush:wash(dir:-12) jitter:.8,18 name:chip

Shading stays inside.

Children clip to their parent. The mottle, dust, veins, bands and eyespot on this forewing are all children of the wing curve. Some are drawn on a 300 by 300 rectangle or run past the edge, but each paints only inside the wing.

  curve pts closed tension:.45 fill:grad(6,-6 120,-72 deep c,.45 shade(c 1),.8 shade(c 2)) stroke:fade(line(c) .5),1.2 brush:wash name:fw
    rect 300x300 at:66,-30 fill:(worley(2 seed:9)-.72)*5+.5 -> [fade(m 0) fade(m 0) fade(m .6)] name:dust
      mask (fbm(simplex(16 seed:4))-.5)*2.5+.5
    each k in 0..6
      curve 6,-20 60,-46+k*12 150,-110+k*20 stroke:fade(deep .25),.7 taper:.05,.3 name:vein

Brushes written in SkSL.

A brush is a small SkSL program that shades each pixel of a fill or a stroke. The wash brush is lifted from lib/moth.art. It grains the paint with fbm, streaks it along a direction and roughens the edge. Each stroke here calls it with a width at each point and a taper.

brush wash strength:.3 scale:1 streak:.5 rag:1 reach:1.5 dir:-25
  sksl """
  float4 shade(Mark m) {
    float g = fbm(m.uv / (16 * scale) + o, 3) - .5;
    float e = m.edge + g * 2 * rag;
    return float4(c, cover(e, m));
curve 70,96 300,70 530,100 740,76 stroke:p.luna.3,[52 78 70 26] taper:.04,.3 brush:wash(dir:0) name:luna

Stamps follow the path.

A stamp is a block of drawing laid along a stroke. Each antenna is one curve. The barbs stamp from lib/moth.art lays a pair of barbs every 2 units and sizes each by how far along the stroke it sits. The fur stamp rims the thorax the same way.

stamp barbs spacing:2 h:9 tint:p.ink
  let l = h*(.25+.75*sin(u*180))*(1-u*.35)
  curve 0,0 l*.35,0-l stroke:tint,.6 taper:0,.7 name:barb_l
  curve 0,0 l*.35,l stroke:tint,.6 taper:0,.7 name:barb_r
    curve 3,-55 14,-72 32,-92 54,-104 stroke:body,[1.8 1.4 1 .5] taper:0,.4 stamp:barbs(tint:body h:9) name:antenna

Noise as paint.

Simplex, perlin, worley and fbm fields fill a shape through a ramp or a list of colours. This hindwing is mottled by fbm. Its dust is worley noise, masked by a second fbm so the dots gather in patches.

  curve pts closed tension:.45 fill:grad(4,-8 88,52 deep c,.4 shade(c 1)) stroke:fade(line(c) .45),1 brush:wash(dir:-60) name:hw
    copy @hw fill:fbm(simplex(22 seed:3)) -> [fade(m 0) fade(m .35)] a:.7 name:mottle
    copy @hw fill:(worley(2 seed:10)-.72)*5+.5 -> [fade(m 0) fade(m 0) fade(m .4)] name:dust
      mask (fbm(simplex(16 seed:11))-.5)*2.5+.5

Motion is a patch.

An anim patches a named part of a drawing. Here it turns the moth’s antennae about their roots on a looping key over 2 seconds, and the moth itself is unchanged. The GIF target plays the loop. A PNG target of the same file draws the frame at 500 ms.

anim twitch dur:2s loop
  .m.antenna pivot:3,-55 rot:key(0 5 -2 0 ease:in_out)
play twitch
moth wing:bone shape:sharp pattern:8 at:200,470 scale:3.6 name:m
