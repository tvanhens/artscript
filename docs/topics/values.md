# values: entry parameters, CLI literals, the values table, expressions, operators, functions, fn

## Entry parameters

`param view:one_of(normal geometry) guides:false` declares named controls in an entry file. Each default's form gives the parameter its type, as for a `def` (see `components`, Parameter types). The first `one_of` word is the default. A plain word default accepts any word. Defaults can use earlier parameters and names available at their declaration. With no overrides, all parameters use their defaults.

`check`, `build`, and `preview` accept repeated `--set name=value`. Values are literals, including numbers, percentages, angles, times, booleans, words, hex colors, strings, sizes, tuples, and lists. Shell-quote values containing spaces or shell punctuation, for example `--set 'offset=12,4'` or `--set 'caption="hello"'`. Calls, arithmetic, and references are not CLI values. An undeclared parameter, a wrong type, or a word outside `one_of` is an error, reported once for the entry. An undeclared name has no source line, so it is reported at the entry file with line 0. A rejected binding stops that entry's evaluation, so no error follows from the value it rejected. Repeating a name uses its last value. The bindings apply to each selected entry, so narrow `build` and `check` with `--only` when entries have different parameters.

Entry parameters cannot duplicate one another or collide with a top-level declaration, import, `let`, or target matrix axis. Built-ins `target`, `t`, `clip`, `scale`, `artboard`, `p`, `true`, `false`, and `none` are reserved parameter names. Local bindings inside components retain their ordinary scope rules.

In entry drawing statements and component bodies, comparing an entry `one_of` parameter with an unlisted word using `==` or `!=` triggers `unknown-word` (L0107). Component parameters shadow entry parameters of the same name. The lint respects local rebinding and names bound by the surrounding scope. It does not inspect `fn` or `anim` bodies.

When an entry file is imported, its parameters bind their own defaults privately. Its exported components can read those values. Caller CLI overrides do not reach the imported file, and its parameter names are not added to the caller's globals. A file without `@target` cannot declare entry parameters.

| kind | examples |
|---|---|
| number | `12`, `.5`, `-3` (artboard units) |
| percent | `50%` of the current frame (the artboard, a parent shape's bounds, a moved group's box around its origin, or a def's `size` box) |
| angle | `30deg`, `.25turn`, bare numbers in `rot:` are degrees |
| time | `200ms`, `2s`, a bare number in a time position is seconds |
| vector / size | `14,0` (no spaces around the comma), `256x256`. A vector is a size, so `rect w,h` sizes from variables. `rect w x h` is E0321. A vector or size has two or three components, as in `14,0,8` and `40x20x10`. The third is a depth in artboard units, so `1,2,50%` is E0320. No key draws in 3D yet, so a key that takes a vector reports E0320 on three components, and the fix says to drop the third. `@artboard` and a `@target` output size take two components (E0206). A two-component value and a three-component value do not mix in arithmetic (E0320). There are no per-axis keys such as `rotx:` or `depth:`. `rot:` keeps one angle, and its 3D form is reserved for an axis and an angle |
| color | `#ff5e5b`, `oklch(.78 .07 55)`, `p.skin.3`, `p.skin` (a ramp's base). A hex color of 3, 4, 6 or 8 digits ends at the first character that cannot continue a name, so `#ff0000+v` is an expression; any other `#` starts a comment |
| list / range | `[a b c]`, `0..8`, `[each k in 0..n -> expr]` |
| brush | `dry`, `dry(strength:.9 dir:45)`, `[chip dry]`; a `brush` declaration, a call on one with overrides, or a stack. See `brushes` |
| path | `path(@body)`, `path([0,0 10,4 20,0])`, `path(pts closed:true)`. One shape's contour, or straight segments through two or more points, open unless `closed:true`. `point`, `tangent`, `length`, and `points` read it; see the path functions below |
| reference | `@body`, `@thorax.sheen`, `@hero.head.eye_l`, `@body.neck` (anchor), `@self`; also `artboard`. A path names every shape, instance, and slot on the way down, and nothing else. A group or a layer is never a segment, so a part inside `group face` under `hero` is `@hero.eye_l`, and a path through one is E0350 with a fix that drops it. A bare `@sheen` reaches `sheen` only at the root of its scope. For a `sheen` nested under `thorax` it is E0350, and the fix names `@thorax.sheen`; when `sheen` sits under several shapes, the error lists every path. A reference to a sibling drawn later in the same block resolves: the reader is evaluated after that sibling and still paints at its own line, so `group name:arm at:@shoulder` written above `group name:body`, which holds `anchor shoulder`, draws behind it. Two siblings that reference each other are E0350 at the earlier one, and the fix is to draw the other first and paint this one behind it with `order:` |

A list is indexed with `.0` or with `.{expr}`, where the braces hold any expression that gives a number or a name: `tones.{mod(row 3)}`, `pts.{i+1}`. A name in the braces is read as its value, and a name that is not bound is read as itself, so `p.{skin}` is `p.skin`. A value that is neither a number nor a name is E0320. On a reference, `@dot.{k}` picks one copy of a family the way `@dot.1` does.

Expressions: `+ - * /` (elementwise on vectors; a number scales a vector, as in `(dx,dy)*.28`, `2*v`, `v/2`; `-v` negates), `== != < <= > >= ~=`, `and or not`, `in lo..hi` (`lo` included, `hi` excluded), `if c then a else b` (each branch takes a tuple, so `if c then 3,4 else 5,6` picks a point; write `(if c then a else b),3` to put the `if` inside a tuple). Write binary operators with spaces on both sides or neither: `w/2`, `a + b`. `-x` after a space starts a new argument. Functions: `min max abs clamp lerp sqrt floor round sin cos atan2 mod` (degrees; `atan2(y x)`, floored `mod(a b)`), `polar(r deg)`, `rand(lo hi)`, `pick(list)`, `concat(a b ...)` (two or more lists or ranges joined in order into one list; any other argument is E0320, and `[v]` wraps one item), the path functions, and the color helpers below. `v.x`, `v.y` read a vector, and `v.0`, `v.1` read the same two numbers, so a table row reads by position at any length. A three-component vector adds `v.z` and `v.2`, and a size reads `.w`, `.h`, and `.z` the same way. Arithmetic is elementwise between two values of the same length, and a number scales either length. `list.1` reads an item of a list, counting from 0, and `list.{i}` reads the item at the value of the name `i`. `.{name}` works on any member path, so `p.{tone}` reads the palette row that the word in `tone` names. A vector literal inside arithmetic needs parentheses: `a,b + v` is the list of `a` and `b + v`, and `(a,b) + v` adds `v` to the vector. A key that wants a vector and gets that pair reports E0320, and the fix says to parenthesize the vector.

Path functions. `path(@body)` is one shape's whole contour as a path value. A position on it is measured on the shape's own contour, as `edge` measures `from:` and `to:`, so a non-uniform `scale:` or a `skew:` on the shape or on an ancestor does not move position `.25` along the contour, and a flip reverses it with the shape. Its samples are vectors in the current local frame, placed the way `edge` places its stretch, so they follow the shape's transform, its warp, and `jitter:`. A group, layer, instance, or artboard is E0320. `path([a b c])` is straight segments through two or more points, open unless `closed:true`; fewer points, or an item that is not a vector, is E0320. `point(p u)` is the point at contour position `u` of the path `p`, and `tangent(p u)` is the unit direction of travel of the placed contour there, both vectors. `u` is a number from 0 to 1, as `edge` takes `from:` and `to:`, and anything else is E0320. Position 0 is where the shape's contour position 0 lies (see `shapes`), and a code-built path starts at its first point. Position 1 is the end of an open path and the start of a closed one. `length(p)` is the arc length over every contour, measured in the frame the value was made in. `points(p)` is one list of the on-curve points of every contour in path order: a `curve`'s points, a `path`'s vertices, a `poly`'s corners, the four quadrant points of a `circle`, and a code-built path's own points. A path with no length, such as `path([5,5 5,5])`, is E0320 under `point` and `tangent`; its `length` is 0 and its `points` still read. A position that a warp hides is E0320 under `point` and `tangent`, and a hidden point is E0320 under `points`. A path value keeps the frame it was made in. A `let` at the top level holds artboard coordinates, and a call under a node holds that node's local coordinates, so a sample is a vector `at:` takes in that frame.

`fn solid(c r) = map.{r}.{c} == 1` declares a function at the top level of an entry file or a library. The parameters are positional names in parentheses, and the body is one expression; a block under the line is an error. A call is `solid(col row)`, with one argument per parameter in order. A call with another count, or with a `key:value` argument, is E0320. The body sees its parameters, the file's other fns, and the file's top-level `let`s and palettes; `p` is the palette of the call site, as in a parameter default. It does not see the caller's locals, and it cannot read an `@` reference: pass the measurement in as an argument. A body that calls `rand` or `pick` is E0324, because a random value is seeded by the draw site that asks for it; pass `rand(0 1)` in as an argument and the call site's seed holds. A fn cannot call itself, directly or through other fns, and a cycle is E0325 at each fn on it. A call that reaches a running fn again through a parameter or a `let`, as in `fn f(g) = g(g)`, is E0325 at the call. A parameter may share the fn's name or a global's; the parameter wins. `use lib { solid }` imports a fn as it imports a def. `use lib as m` holds it as the value `m.solid`, and `let solid = m.solid` makes it callable, because only a name can be called. `fn` opens a declaration only as a line's first word.
