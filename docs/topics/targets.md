# targets: @target keys, entry files and libraries, use, the manifest palette p

- An **entry file** starts with one or more `@target` lines. Any file without one is a **library** and may only hold `use`, `palette`, `style`, `finish`, `def`, `rule`, `let`, `anim`.
- `@target produce/peach.png 1024x1024 scale:1,2` writes `peach.png` and `peach@2x.png`. The size is the canvas in canvas units, before `scale:`. Each PNG is the canvas times its scale, rounded up to whole pixels, so `32x20` at `scale:2` is 64x40 pixels. `.svg` targets write SVG. `.gif` targets write one GIF at scale 1; `scale:` does not add `@2x` copies or change the stroke sample. Keys: `bg:none|<color>`, `as:<label>` (the file reads it as `target`), `scale:` (the file reads the scale of the output it draws as `scale`: a `.png` output's own number, and 1 in a `.svg` or `.gif`, so a def can keep a constant pixel width with `stroke:ink,1/scale`; a def parameter, `let`, or global named `scale` wins, and the file is evaluated and checked once for each scale), `profile:vector|svg|raster|auto` (`vector` and `svg` need an `.svg` target, and an unknown word is an error), `fps:` (default 24), `dur:`, `clip:` (the file reads it as `clip`, default `none`), `t:` (the time a still draws, default 0), `pivot:` (a point in canvas units, `pivot:48,96`, `pivot:50%,100%`, or an anchor such as `pivot:@leg.hip`; a node is E0206, and so is `pivot:` on a `.gif`), `palette:<palette>` (a palette or a `use … as` palette module that `p` names for everything the target draws; any other value is E0206), a bare `viewport` marks the canvas as a crop of a larger scene and turns off the `off-canvas` lint for that target, `each k:[a b]` fans out a matrix interpolated as `{k}` in the path. A path may also hold `{scale}`, the scale number (`0.5`, `2`), and `{w}` and `{h}`, that output's size in pixels, so `icon_{w}.png` with `scale:1,2` on `32x32` writes `icon_32.png` and `icon_64.png`. A `.png` path that holds any of them drops the `@Nx` suffix, and a path without one keeps it. A `.svg` or `.gif` path fills them with scale 1 and the canvas size. An axis named `w` or `h` is E0206, because it would clash with `{w}` and `{h}`. `fmt` prints `clip:` after `each`. `bg`, `scale`, `as`, `fps`, `dur`, `t`, `clip`, `profile`, `pivot`, and `palette` are never axes, so `clip:[idle blink]` stays a `clip:` error. An unknown key or bare word is an error. `target` is reserved, so `let target = 1` is an error. `target` holds the `as:` label as a word, or `none` when the target has no `as:`. It never holds the output path. The `unknown-target` lint (L0106) warns when the entry file compares `target` with `==` or `!=` to a word or string that no `@target` in that file can give it, and it names the labels. A name the file binds or imports is not checked, because its value is known only when the file runs. A library is not checked. A GIF needs an opaque `bg:`, at most one frame per centisecond of `dur`, and at most 256MiB of raster and 256MiB of retained frames.
- Each `.png` and `.svg` entry in `art-manifest.json` carries `pivot` (`null` without a `pivot:`) and `anchors`, the position of every anchor the file placed by the path an author writes after `@` (`body.neck`). Both are in that output's pixels, so `x@2x.png` holds twice the numbers of `x.png`. A `_` anchor inside a def is left out. A `.gif` entry carries neither, because its anchors move per frame.
- `use face/eye` imports a library from the manifest's lib roots. `use palette/dusk as p` aliases it. `use face/parts { eye blush }` imports names. Names starting with `_` stay private.
- The `unused` lint reports an imported name the importing file never reads. `palette elite from house` reads `house`. A library's top-level `let` is an export, like a `def`, so the lint does not report it. A private `_` let is not an export, and the lint reports it when nothing reads it.
- A `use` that fails (the library does not parse, is missing, or lacks a listed name) is reported once, at its cause. Its names stay quiet where they are used, and after a bare `use x` so does any unknown verb, style, effect, or anim. A broken manifest palette does the same for `p`.
- The manifest's default palette is available as `p` in every file. See `manifest`. A `palette:` key on a `@target` or on a def instance rebinds `p` for everything drawn under it, library defs included. An inner `palette:` replaces an outer one. A file that binds `p` itself, with `palette p`, `let p`, or `use … as p`, keeps its own. A library's top-level `let` is evaluated once when the library loads, so `let tint = p.blue.2` keeps the manifest color under `palette:`. Read `p` in the def body or in a parameter default to follow the key. The `unused` lint counts `palette:elite` as reading `elite`.
