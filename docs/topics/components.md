# components: def and entry parameters, size box, slots, patches, let/if/each, style

Entry files use `param name:default` with the same parameter types and `one_of` words as `def` (see Parameter types below). A declaration can name several parameters. `param` does not create a component or a special drawing block. Ordinary expressions, conditionals, shapes, and effects read the bound values. See `values` for entry scope and CLI literal syntax.

```
def eye size:10 iris:p.sky.3 look:0,0
  circle size fill:#fff name:white
    circle size*.55 at:look*size*.3 fill:iris
  anchor brow 0,-size
  slot lashes at:0,-size*.8
```

- Positional arguments fill the parameters in order (`eye 9 at:-14,0`), so `def d a:1 b:2` called as `d 5 6` sets `a` to 5 and `b` to 6. A parameter's type is read from the form of its default (see Parameter types). An instance also takes the node keys, `seed:n` pins every seed inside it, and `palette:elite` rebinds `p` for everything drawn under it, slot content and parameter defaults included. A `palette:` that is not a palette is E0320. A parameter whose default is `p` or a palette takes a palette. Passing it `p` when no palette is bound to `p` is E0320 at the call, and the fix names the manifest's `[defaults] palette` and the target's `palette:` key. A key the def does not declare is E0321. An instance takes no `fill:`, `stroke:`, or `blur:` of its own, since a def draws several shapes: for `fill:` or `stroke:` the fix names `palette:` and a color parameter, and for `blur:` it names an `fx blur N` line under the instance.
- `kind:one_of(floor_top fill fill_b)` declares the words a parameter may take. The first word is the default. A call that passes any other word, or anything that is not a word, is E0320 at the call, and the message lists the allowed words. Positional, named, and alias-fixed arguments are all checked. An alias that fixes the parameter to a word is checked at the alias line. One that fixes it to a name holding a word, such as a matrix axis, a `param`, or a `let`, is checked at each instance. In the def, comparing `kind` with `==` or `!=` to a word outside the list warns with the `unknown-word` lint (L0107), unless the body rebinds `kind` or the word is a name the body binds or another parameter. A plain word default such as `kind:floor_top` takes any word. `one_of` is only a parameter default, and its arguments are bare words.
- `size` is the def's box, centered on the origin. `size:40` is a square. `size:72x32` is 72 wide and 32 tall. A bare percent uses the smaller side. Percents in the body measure that box, and a child with no `at:` stays at the origin.
- Components are values, so `outfit:tunic` can be placed as `outfit`, and `none` draws nothing. A def may reuse a shape word. `def circle` is that component, not the built-in circle.
- `def arm_l = hero_arm tone:-1` declares an alias: `hero_arm` with `tone` fixed. An instance of `arm_l` is an instance of `hero_arm`, so it has `hero_arm`'s anchors, parts, and slots directly. `@arm_near.hand`, `.hand fill:p.red`, and `glove:` work as on a `hero_arm` instance, and `arm_l` draws the same pixels as `hero_arm tone:-1` at the same place, seeds included. An unnamed `arm_l` counts as a `hero_arm` among its unnamed siblings, so its path is `hero_arm~1`. A call fills the parameters the alias leaves open, positionals in the def's order, and may still pass `seed:`, `palette:`, and the node keys. Passing a key the alias fixed is E0321. An alias may fix any key a call takes except `name:`, which belongs on the instance, and a key the def does not declare is E0321 at the alias line. A fixed argument is evaluated like a parameter default: in the alias's module, with the instance's palette as `p`, so `palette:elite` on the instance recolors a fixed `tone:p.skin.3`. An alias has no body. It may alias another alias or an imported def, and it may be written above the def it names. A library `let` sees an alias declared above it, as it sees a def. An alias of itself, or of a name that is not a def, is E0323.
- `slot name` exposes an insertion point, filled by the caller with a `name:` block. A def body may hold `fx`, which attach to every instance and run before the call site's. A mask, a slot fill, or a patch cannot sit directly in a def body. Slot content is its own scope. `@part` there searches the content, then the host, then the caller. A def body sees only its own names. `needs:@torso` imports the host's `torso`, and a missing host or a missing part is an error at the call.
- `.arm_r rot:-20`, `.cape off`, and `.head.eye_l iris:p.accent` override a declared name from the instance block, in source order, with the last one winning. A patch path is spelled like a reference: every shape, instance, and slot on the way down, and never a group or a layer. `.head.eye_l` reaches the `eye_l` under `head`, whether `head` is a shape, an instance, or a slot. A bare `.eye_l` reaches `eye_l` only at the def's root; for a part nested under a shape it is E0340, and the fix names the full path. `.eye.0` reaches one copy of a family, and `.eye.1 off` hides that copy. A copy index follows the shape whose loop it picks, so `.thorax.1.sheen.0` is the first `sheen` of the second `thorax`. A segment may be a keyword when the part is a slot of that name, as in `.mask off`. Hiding the instance with `off` still checks a hop through it.
- A part whose name starts with `_`, as in `name:_core`, is private to its def. `@_core` works in the def body. A patch or an anim path from outside the def that names `_core` is an error, and `.*` skips it. `.*` also skips anchors, which have no node to change. The entry file has no caller, so its own `_` names stay patchable.
- `let w = if build == slim then 34 else 42`, `if`/`else` (a statement `if` takes a block, not `then`), and `each x in [..]` / `each i in 0..8` are bounded control flow. `each i in 0..8` runs 8 times, with `i` from 0 through 7. `each i, x in list` also binds the position `i`, from 0 in iteration order, with the index first, over a list or a range. `[each k in 0..n -> expr]` builds the list, and `[each i, x in list -> expr]` binds the position there too. A loop index does not change the seeds inside the loop.
- A parameter may hold a brush: `def stone tone:p.stone.3 brush:chip` and `rect size fill:tone brush:brush` in the body, or `brush:brush(scale:.5)` to re-call it with overrides. `brush` is a legal parameter name. An instance passes it like any parameter (`stone brush:dry`, `stone brush:none`); `brush:` on an instance whose def has no such parameter is E0321. A parameter whose default is a brush, or `none(chip)` naming one, is typed by that brush declaration: an instance passes a brush or `none`, and a call on it checks its arguments against that declaration, so a bad key is E0361 for every instance. When the instance passed `none`, the call is `none`, so the body stays valid under `brush:none`. A `none(brush)` parameter names no declaration, so a call on it is checked only against the brush the instance passed, and only when it passed one. An `if` default whose branches name two different brushes types the parameter the same way. Calling a parameter that is not brush- or stamp-typed is an unknown function. A parameter may hold a stamp the same way: `def vine stamp:dots` with `curve 0,0 100,0 stamp:stamp(spacing:10)` in the body, an instance passes a stamp or `none`, and a call on the parameter is checked against the declaration (E0366). A def body also inherits the paint keys of the layer or style the instance sits in, `brush:` and `stamp:` included, so a shape in the body with no `brush:` of its own takes the layer's.
- `style ink stroke:p.ink,2` with `style:ink` applies those keys to a node and its descendants. A style takes keys only, never a block. A style holds keys that children inherit, while a finish holds effects that one node gets.

## Parameter types

A parameter's type is read from the form of its default before anything runs, so `ramose check` knows every type without evaluating, and a tool can read them from the source. The default's value is still computed when an instance needs it, with the instance's palette as `p`.

| default | type |
|---|---|
| `10`, `50%`, `90deg`, `200ms`, `rad(..)`, `rand(..)` and the other math functions | number |
| `min(..)`, `max(..)`, `clamp(..)` | a field when given a field, otherwise a number |
| `abs(..)`, `sqrt(..)`, `floor(..)`, `round(..)`, `sin(..)`, `cos(..)` | the type of the argument: a vector or three-component vector for one, a field for `abs` of a field, otherwise a number |
| `lerp(a b t)` | a color when `a` and `b` are colors, otherwise the type of `a + b` |
| `72x32`, `0,0` (two numbers), `polar(..)` | vector |
| `40x20x10`, `4,2,1` (three numbers) | three-component vector |
| `true`, `false` | boolean |
| `#fff`, `p.sky`, `p.sky.3`, `brand.paper`, `mix(..)` and the other color functions | color |
| `simplex(..)`, `value(..)` and the other field functions | field |
| `cylinder(..)`, `corners(..)` | warp |
| `[..]`, a tuple holding a non-number such as `p.ink,2` | list |
| `0..4` | range |
| `"text"` | string |
| `@self`, `@body.neck`, `artboard` | node reference |
| `artboard.w`, or a measure such as `.cx` of a name that holds a node reference | number |
| `one_of(a b)` | one of those words, the first by default |
| `none(T)` | T, with `none` as the default |
| `a + b`, `-a` | a number from numbers, a vector or a three-component vector when either side is one (the two do not mix), a field when either side is a field |
| `a < b`, `a and b`, `not a` | boolean |
| `if c then a else b` | the type of both branches, which must agree; two different defs, brushes, or stamps give a component, brush, or stamp that names no declaration |

A bare name has the type of what it names, looked up as a body looks it up: an earlier parameter, an entry `param`, `target` or `clip` (a word), `t` or `scale` (a number), a matrix axis, `p` (a palette), then a top-level name of the file or of a file it imports, the later `use` winning when two files imported whole export the name, as it does when the file runs. A def or an alias is a component of that def. A brush or a stamp is that brush or stamp. A palette, or a module imported with `use .. as m`, is a palette. A `fn` is a function and a `rule` is a rule. A `let` has the type of its right side by these same rules, so `ink:stone_line` after `let stone_line = mix(..)` is a color. A name that names nothing is a word, so `kind:floor_top` takes any word. `m.name` has the type `name` has in that file.

`none(T)` declares an optional parameter: its default is `none` and its type is `T`. `T` is one of the type words `bool number vector vector3 color palette field range list string word component ref rule fn brush stamp warp path`, or the name of a def, brush, or stamp, so `brush:none(chip)` is checked like `brush:chip` and `outfit:none(component)` takes any component. A type word wins over a name. Like `one_of`, `none(..)` is only a parameter default; anywhere else it is E0320.

A call passes a value of the parameter's type, or `none` to any parameter but a `one_of`, which takes only its words. A component also takes a word, a list takes a range and a range takes a list, a warp takes a list, a color takes a field, a vector takes a number, and a palette takes the module a palette file binds as. Anything else is E0320 at the call, and the message names the type.

A default whose type cannot be read from its form is E0326 at the parameter, reported once by `ramose check` whether or not anything instantiates the def, in library files too, and the file is not evaluated. A `use` that reaches such a file is E0214 at the `use` line, once per target, with a note naming the file's first error, so the importing target is not built. This covers a bare `none`, a call to a `fn` or to a function with no known result type such as `pick`, an `if` whose branches disagree, an index such as `pts.{1}`, a member of something that is not a palette, module, vector, or node reference, or a reference member that is not a measure, arithmetic with no type, and a `let` that is itself untypeable or reads itself. The fix names `none(T)` and a default whose form shows its type. A brush key whose type is not a number, color, or vector is E0363 at the key. An alias's fixed arguments are checked against the def's parameters once, at the alias line.
