# anim: t, key, anim, play, preview frame sheets, node keys, explain

`preview --time .5` draws one time in seconds. `--times 0,.5,1` draws explicit times, and `--frames 8` samples a target's duration evenly in `[0,dur)`. Even sampling excludes the loop endpoint. Include the endpoint explicitly with `--times` to compare a seam. `--columns 4` lays the frames out as a contact sheet. Without it, frames form one horizontal strip. `--clip swing` selects a target with `clip:swing`, preserving its clip context. A named crop uses the union of its bounds across the sampled frames, so all cells share an artboard region. See `cli`.

`t` is the anim's local time in seconds. `clip` is the target's `clip:` name, or `none`. It is fixed for each output, so `if clip == idle` may choose what to play.

A scene's structure does not change over time. `t` and `key(...)` may appear only in a patch value inside an `anim`. Every node exists for the whole clip with the same verb, parent, draw order, key, and seed, and an anim changes only the values of those nodes. A patch may set any argument that keeps that tree: transforms, `a:`, paint, and the numbers that shape a node, such as `r:` or a curve's points. No `if`, `each`, `repeat` or `grid` count, component or slot choice, `path` string, `seed:`, anim `dur:`, or `play` `start:` may depend on time. The rule holds through a `let`, a `fn`, and a def parameter: `.mouth open:key(0 1 0)` may move the points of the `mouth` def, but the def may not branch on `open`. To show a part for only some of a clip, draw it always and animate its `a:`. The rule exists for engine export. An engine animation track drives a node that exists for the whole clip, and only a flipbook of frames can carry a node tree that changes. `t` or `key(...)` outside an anim patch value is E0345 at that line. A def parameter that an anim patches carries time, and so does a `let`, a `fn` argument, a stamp argument, or a patch in an instance block computed from it, whether or not the play is live on the frame. A stamp argument computed from `t` or `key(...)` in a patch value carries time too, as in `.eye s:dots(k:key(0 1))`. An `if`, an `each`, a `repeat` or `grid` count, `path` data, `seed:`, a verb, a stamp's `count:` or `spacing:`, or a `play` `start:` that reads one is E0345 at that line, in the file that holds it, with a note that names the patch. A branch on the geometry of an animated node, such as `if @face.cx > 0` after `.face at:key(0 6)`, is not reported.

```
key(0 6 0)
key(0 1 1 0 at:[0 .3 .7 1] ease:in_out)
anim idle dur:2s loop
  .face at:0,key(0 6 0)
  .leaf rot:key(-4 4 -4)
anim blink dur:200ms
  .eye lid:key(.6 1 .6)
play idle start:0s
```

- `key` samples the anim's local time over the anim's `dur:`, or over its own `dur:` when it has one. Values are spaced evenly unless `at:` lists fractions from 0 to 1. The default curve is smooth. `ease:` is `linear`, `in`, `out`, `in_out`, or `hold`, one name or one per segment. `loop` wraps.
- Numbers, angles, vectors, and sizes interpolate. Colors interpolate in OKLab. Words and booleans step. A component may not change over time, by the rule above. Anything else is an error.
- `anim` is a declaration. Its body is patch lines. `at` and `rot` add to the rest pose. A percent rest `at` is measured against the node's frame before a numeric offset is added. `scale` multiplies. `abs(v)` on those three sets the value. Every other argument is set, except `name:`, which stays on the draw. A patch expression is seeded from the anim's file, the owner key, the anim's name, and the patch's path, so a comment or a blank line keeps its value. A `style:` word from the anim is resolved in the anim's module. `play` is a statement at the top of an entry file or under an instance. `play none` does nothing. Plays apply in source order after static patches. A play under an instance in a `def` body applies in the order the instances are evaluated, which is source order except that an instance that references a later sibling waits for it (see `values`), and an entry-file play that reaches the same node wins over it. A top-level `play` is scheduled before anything is drawn, so its `start:`, its anim's expressions, and an `if` or `each` around it cannot read geometry such as `@name.w` (E0344). The last set value wins. A `let` inside `if` or `each` under an instance stays in that branch. A direct `let` under the instance is visible to later plays there.
- A named node's key ignores layers and groups, so `layer body` holding `name:robe` is `robe`. An unnamed node's key is `verb~N` under its parent. `explain` prints the key, including nodes drawn in a mask block. A `~` means the node is not addressable. A node that drew a seed from its key is marked `seed`.
