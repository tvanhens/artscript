# fields: noise fields, fbm, ridged, field fills and masks, seeds

`simplex(40)`, `perlin`, `worley`, `value` take a feature size, `seed:` and `oct:`. Wrap them with `fbm(f)` or `ridged(f)` and combine them with arithmetic. Use `fill:fbm(simplex(30)) -> p.stone` to map a field through a ramp or a list of colors, or a `mask worley(20) > .6` child line to threshold one into a shape (`<`, `<=` and `>=` work too, with the field on either side). `seed:n` sets the seed, so `simplex(16 seed:1)` is the same noise in any node and file. `seed:` works the same on `rand`, `pick`, `blob`, `jitter:`, and `fx grain`. Without it, the seed is a hash of the file and the node's key, and each draw in a statement or an `each` iteration gets its own. A named node keeps its seed when other nodes change. An unnamed node's seed can shift when a sibling with the same verb is added ahead of it, and `positional-seed` warns. Add `name:` or `seed:` to pin it.
