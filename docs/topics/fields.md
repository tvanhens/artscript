# fields: noise fields, fbm, ridged, field fills and masks, seeds

`simplex(40)`, `perlin`, `worley`, `value` take a feature size, `seed:`, `oct:` and `wrap:`. Wrap them with `fbm(f)` or `ridged(f)` and combine them with arithmetic. `wrap:64` makes the field repeat every 64 units of the node's frame on both axes, and `wrap:64,32` sets x and y apart, so copies of a tile or a scrolling layer join with no seam wherever the node sits. The feature size snaps so a whole number of cells fits each period: `simplex(12 wrap:64)` draws 5 cells of 12.8. `fbm`, `ridged` and `oct:` keep the period. A `wrap:` that is not a positive number or a pair of them is E0320. Use `fill:fbm(simplex(30)) -> p.stone` to map a field through a ramp or a list of colors, or a `mask worley(20) > .6` child line to threshold one into a shape (`<`, `<=` and `>=` work too, with the field on either side). `seed:n` sets the seed, so `simplex(16 seed:1)` is the same noise in any node and file. `seed:` works the same on `rand`, `pick`, `blob`, `jitter:`, and `fx grain`. A `seed:` that is not a number is E0320 wherever it is written. Without it, the seed is a hash of the file and the node's key, and each draw in a statement or an `each` iteration gets its own. A `mask` field seeds from the node it masks, so adding a child to that node leaves the mask's noise alone, and a mask under a named node is pinned. `seed:n` on a def instance replaces the file and the instance's key with the def and `n` for every seed inside it, slot content and the call's `fx` included. So `stone_block seed:7` draws the same detail at any place, from any file, as the asset entry file that writes `stone_block seed:7`. A seeded instance inside it uses its own `seed:`. A def that declares a `seed` parameter receives the value as that parameter instead. A named node keeps its seed when other nodes change. An unnamed node's seed can shift when a sibling with the same verb is added ahead of it, and `positional-seed` warns. Add `name:` or `seed:` to pin it.
