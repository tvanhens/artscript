# cli: commands, flags, docs topics, exit codes

`artscript build [--only 'glob']... [--allow-warnings] [--backend auto|gpu|cpu]`, `check [--json]`, `fmt [--check] [FILE...]`, `explain <file>`, `init`, `docs [TOPIC...]`. `--only` matches an entry file or an output path. `*` matches within one directory, `**` crosses directories, `?` matches one character, and `{a,b}` matches either alternative. Repeat `--only` to build the union of its globs. A glob that matches no target is E0200, and nothing is built. A glob that matches only a file with errors reports those errors and no E0200. A brace without its partner prints usage and exits 1. With no files, `fmt` rewrites every `.art` file. `fmt --check` lists files that would change and writes nothing. `check` evaluates each still once and samples each GIF, and it does not render. `check --json` prints `{"diagnostics": [...]}`. Each diagnostic has `severity`, `code`, `file`, `span` (`line`, `col`), `node`, `target`, `message`, `notes`, and `fix`. `target` is the first output path of the target whose evaluation raised it, and it is empty for a plan error and for a diagnostic about a file's own text, such as `raw-color`, `unused`, or a parse error. A diagnostic raised in a library has the note `in <entry>:<line>`, the innermost entry-file statement that reached it. `check` and `build` print a diagnostic once per target, so two targets that reach one library line print two diagnostics. An unknown flag on any command prints usage and exits 1. Exit codes: 0 ok, 1 compile error or a `fmt --check` diff, 2 an assert failed, 3 only warnings. When the reader closes the output pipe, as `head` does, the command stops printing and exits with the same code.

`docs` prints the core card from `docs/language.md`, then a `## Topics` index with one line per file in `docs/topics/`: the topic name and the summary from the file's first line. `docs <topic> [topic...]` prints the core card, then each named topic file in the order given, separated by a blank line. Name every topic a task touches in one call. An unknown topic prints an error and the topic list to stderr and exits 1. `docs` runs from any directory, so it always matches the installed binary.
